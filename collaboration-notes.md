## Ground rules
1. **Stay in your lane.** CL = `app/Http/Controllers/Admin/**`, `resources/views/admin/**`, admin route group. CO = `Api/**`, `Portal/**`, `app/Models/**`, `database/migrations/**`, `app/Services/**`. Full list in `plan.md` §2.
2. **Migrations are CO-owned.** If CL needs a new column/table, log it under "Schema Change Requests" below instead of writing a migration. This avoids two agents generating colliding timestamped migration files or racing `php artisan migrate` against the same sqlite DB.
3. **`routes/web.php` is CL's file.** CO's new routes go in `routes/portal.php` (new file) or `routes/api.php`, never appended to `web.php`. If CO genuinely needs a `web.php` change, log it below first.
4. **Claim before you build.** Before starting a task from `tasks.md`, add a line under "In Progress" below with your name, the task, and the file paths you're about to touch. Remove it (or move to done) when finished.
5. **Don't run destructive DB commands without a note here first** — `migrate:fresh`, `db:wipe`, etc. against the shared sqlite file will blow away the other agent's test data.
6. **Keep `php artisan test` green.** If you leave it red, say so explicitly in this log with why, so the other agent doesn't waste time debugging your in-progress work.
